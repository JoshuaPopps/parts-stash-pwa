Parts Stash

Every spare part on the shelf — where it is, what it fits, and what it cost.

Add a part

Name and quantity are all it takes — the rest is optional. A part with no cost entered has no value in the totals; the summary says so instead of guessing. Cost is per unit, never a total.

Summary

Value = quantity × cost each, both typed in by you. A part with no cost entered has no value in the totals — the summary counts it as unpriced instead of guessing a price.

Bikes

Bikes live in the shared Pocket Garage roster — the same b1/b2/b3 list the other apps use. Add a bike here and it is added to that roster for every app. There is no delete-bike here: roster management belongs to the landing dashboard, so a mistyped bike is removed there, not here.

Your data

No account, no server, no sync. Your parts live in this browser's local storage. Back them up with Export — one JSON file.

Export

The backup is the whole parts stash — every bike, every part. The per-bike export below is one bike's parts, as JSON or readable plain text.

Import

Import replaces the current parts stash. Export first if you want to keep it. Parts pointing at a bike the shared roster doesn't have yet still load — they show under their roster key until that bike is added.

Try it out

Loads example parts on the shelf so you can see the search, the totals, and what an unpriced part does to the value — before entering your own parts. The example prices are example prices only.
